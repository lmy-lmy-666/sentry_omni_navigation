## 1. 整体架构

```
┌─────────────────────────────────────────────────────────────────┐
│                      两块 STM32F407 板子                          │
├─────────────────────────────┬───────────────────────────────────┤
│   sentry_chassis_new        │   sentry_gimbol_new               │
│   (底盘板 — 主控)            │   (云台板)                         │
│                             │                                   │
│   ■ 4×M3508 牵引电机         │   ■ 2×GM6020 云台电机              │
│   ■ 4×GM6020 舵向电机        │   ■ 1×Damiao DM4310 偏航电机       │
│   ■ BMI088 IMU              │   ■ BMI088 IMU                    │
│   ■ 裁判系统 UART            │   ■ 遥控器 SBUS                    │
│   ■ USB-CDC (与 ROS 通信)    │   ■ 拨弹/射击电机                  │
│   ■ CAN1+CAN2 总线           │   ■ CAN1+CAN2 总线                 │
│   ■ PM01 电源模块            │   ■ 自瞄视觉                       │
└─────────────────────────────┴───────────────────────────────────┘
```

**两块板子通过 CAN 总线互联**。底盘板是主控，负责接收 ROS 导航指令、裁判系统数据、执行底盘运动；云台板负责云台稳定和射击控制。

## 3. 通信总线详解

### 3.1 CAN 总线

```
底盘板
  CAN1 ── GM6020 舵向电机 (0x205-0x208 RX, 0x1FF TX)
       ── RC 转发数据 (0x113, 0x115 RX, 来自中间 MCU)
       ── 射击数据发送 (0x110 TX → 云台板)
  CAN2 ── M3508 牵引电机 (0x201-0x204 RX, 0x200 TX)
       ── Damiao DM4310 云台电机 (0x01)
       ── PM01 电源模块 (0x601/0x602 TX, 0x610/0x612 RX)

云台板
  CAN1 ── GM6020 云台电机 (0x205-0x206 RX)
       ── 射击电机 (0x141 RX)
       ── 裁判数据 (0x110 RX, 从底盘板转发)
  CAN2 ── Damiao 电机反馈 (0x01 RX)
```

### 3.2 UART / USB

| 接口 | 板子 | 协议 | 用途 |
|------|------|------|------|
| UART3 | 两块板都有 | SBUS (DMA双缓冲) | DT7/DR16 遥控器接收 |
| UART6 | 底盘板 | 裁判协议 (DMA双缓冲) | 裁判系统数据收发 |
| **USB-CDC** | **底盘板** | **自定义协议** | **与 ROS 通信的核心链路** |
| UART1 | 两块板都有 | Vofa JustFloat | 实时调试波形 |

### 3.3 USB-CDC 协议（ROS ↔ STM32）

**这是决策/导航系统与电控通信的唯一链路。**

#### ROS → STM32（下行，19 字节）

```
┌──────┬─────┬─────────┬─────────┬─────────┬──────┬───────────┬──────────┬──────────┐
│ 0xA0 │ len │ lx(f32) │ ly(f32) │ az(f32) │ mode │ ros_state │ reserved │ CRC16    │
│ 帧头  │ 长度 │ 前向速度 │ 横向速度 │ 角速度   │ 模式 │ 状态      │ 保留      │ 校验     │
└──────┴─────┴─────────┴─────────┴─────────┴──────┴───────────┴──────────┴──────────┘
```

- `lx/ly`: 底盘坐标系下的线速度 (m/s)，ROS 导航包发布
- `az`: 角速度 (rad/s)
- `mode`: 0=normal, 1=spin_low, 2=spin_high, 3=estop

#### STM32 → ROS（上行，54 字节）

```
┌──────┬─────┬─────────┬─────────┬────────────┬───────────┬──────┬───────────┬──────┐
│ 0x50 │ 51  │ pitch   │ yaw     │ current_hp │ game_prog │ team │ rfid_base │ ...  │
│ 帧头  │ 长度 │ 俯仰角   │ 偏航角   │ 自身血量    │ 比赛阶段   │ 颜色  │ RFID状态  │      │
└──────┴─────┴─────────┴─────────┴────────────┴───────────┴──────┴───────────┴──────┘
```

包含：IMU 姿态、血量、比赛阶段、颜色、RFID 状态、所有友方血量、event_data

> **关键数据结构定义在 `Task/Src/navigation_auto.c`**

## 4. 核心控制回路

### 4.1 导航指令执行流程

```
ROS (omni_decision_sample)
  │  发布 lx, ly, az 速度指令
  ▼
USB-CDC 虚拟串口
  │  帧格式: 0xA0 | len | lx | ly | az | mode | ...
  ▼
STM32: recieve_Navigation() [navigation_auto.c]
  │  解析帧头 0xA0，提取速度数据
  ▼
Chassis_control() [ChassisControl.c] — AUTO 模式
  │  Speed.vx = navigation→ly / 0.12 * 60 * 19  (m/s → RPM)
  │  Speed.vy = navigation→lx / 0.12 * 60 * 19
  │  若受击 (flag_groy==1) 且静止 → 自旋 vw=12
  ▼
Absolute_Cal() [AGV.c]
  │  用云台偏航角旋转速度矢量 (车体系 → 场地系)
  ▼
AGV_angle_calc() [AGV.c]
  │  逆运动学: 每个轮子 atan2 计算目标舵角
  │  半圈优化 + 最短路径 + 方向翻转
  ▼
AGV_calc() [AGV.c]
  │  每个轮子目标牵引 RPM
  ▼
compute_data() [ChassisControl.c]
  │  Ramp 斜坡限速
  │  PID 级联: Traction_S(PID) → 电流 | Rudder_P → Rudder_S → 电压
  ▼
Power_Control() [PowerControl.c]
  │  舵向功率估算 + 牵引功率预算 (100W 硬限)
  │  超预算 → 比例缩放 + 二次方程求解电流上限
  ▼
CAN 发送: M3508_Motor_Ctrl() / GM6020_Motor_Ctrl()
  │  CAN ID 0x200 (4×M3508 电流), 0x1FF (4×GM6020 电压)
  ▼
电机执行
```

### 4.2 底盘运动学

**四轮独立转向 + 独立牵引**（非麦轮），车轮布局为正方形对角 45° 排列。

- 运动学常数: `0.707107` (= sin 45° = cos 45°)
- 每轮 3 个 PID: Rudder_P(位置) + Rudder_S(速度) + Traction_S(速度)
- 还有一个 `FollowPID` 用于云台跟随模式
- 舵轮零点 (编码器值): 7781, 7287, 5090, 5645

### 4.3 云台控制

- **GM6020 电机** ×2: 位置-速度 PID 级联控制
- **Damiao DM4310** ×1: MIT 模式控制 (pos/vel/Kp/Kd/tor)，偏航轴用
- 自瞄模式 (`zimiao_flag==1`): 位置 PID 跟踪自瞄视觉给出的编码器偏移
- 搜索模式 (`zimiao_flag==0`): 慢速扫描 -0.4°/周期

## 5. 传感器与估计器

### 5.1 姿态解算管线 (1kHz)

```
BMI088 (SPI1)
  │  陀螺仪 ±2000dps, 加速度计 ±16g
  ▼
IMU 参数校正 (安装偏置补偿)
  ▼
QuaternionEKF (四元数扩展卡尔曼)
  │  状态: [q0,q1,q2,q3, bias_x, bias_y] (6D)
  │  观测: 重力方向 (加速度计)
  │  特征:
  │    - 偏航角仅靠陀螺积分 (加速度计无法修正偏航)
  │    - 自适应噪声缩放 (残差检验)
  │    - 收敛保护 (50次连续异常 → 重置)
  │    - 遗忘因子 λ=0.9996 防止过度收敛
  ▼
输出: Roll/Pitch/Yaw, 方向余弦, 重力分量, 运动加速度
```

### 5.2 Kalman Filter 库

通用 Kalman 滤波器，支持：
- 可变维度 (xhatSize, uSize, zSize)
- **自动测量维度调整** (传感器不同采样率时动态重构 H/R/K 矩阵)
- 可跳过单步 (SkipEq1-5 标志位)
- 用户自定义函数钩子 (User_Func0-6)
- ARM CMSIS-DSP 加速矩阵运算

## 7. 模式切换

通过遥控器左拨杆 (`s[0]`) 切换:

```
s[0] = DOWN  →  STOP   (停车，所有电机输出置零)
s[0] = MID   →  RC     (遥控器直控)
s[0] = UP    →  AUTO   (ROS 导航自主控制)
```

右拨杆 (`s[1]`) 设置 `behavior_state`:
```
s[1] = DOWN  →  1 (巡逻/防守)
s[1] = MID   →  2 (前压)
s[1] = UP    →  3 (进攻)
```

> **注意**: 遥控器 SBUS 数据由中间 MCU 解码后通过 CAN (0x113, 0x115) 转发给底盘板。底盘板本地的 SBUS 解码代码存在但不直接使用。

## 8. 功率管理

### 硬编码策略（实际使用）

```
底盘总功率 = 100W (chassis_power)
优先级: 舵向电机 > 牵引电机

1. 估算 4 个 GM6020 舵向电机功率
   P = a + K0·I·ω + K1·ω² + K2·I²  (二次模型)

2. 剩余预算 = 100W - 舵向功率

3. 估算 4 个 M3508 牵引电机功率
   若超预算 → 比例缩放 → 二次方程求解电流上限
```

### 裁判动态功率（备用代码，已注释）

从裁判系统读取 `chassis_power_buffer` 和 `chassis_power_limit` 做动态功率预算。当前未启用，使用硬编码 100W。

## 12. 对决策系统 (omni_decision_sample) 的接口总结

决策系统通过 **USB-CDC** 与电控交互：

### 发给电控 (决策 → 底盘板)
```
lx, ly, az  →  底盘速度指令 (车体坐标系)
mode        →  0=normal, 1=spin_low, 2=spin_high, 3=estop
ros_state   →  ROS 状态 (0=init, 1=ready, 2=running, 3=fault)
```

### 从电控收到 (底盘板 → 决策)
```
pitch, yaw         →  IMU 姿态 (rad)
current_hp         →  自身血量
game_progress      →  比赛阶段
team_colour        →  颜色 (1=红, 0=蓝)
rfid_base          →  是否在补给区
ally_*_robot_HP    →  所有友方血量
event_data         →  比赛事件 (bit25-26 提取)
```

### 依赖关系
```
omni_decision_sample (ROS)
  │  发布 lx/ly/az 到 USB-CDC
  ▼
底盘板 Chassis_Task (1kHz)
  │  执行速度控制
  ▼
底盘板 Navigation_Task (1kHz)
  │  返回 IMU + 裁判数据
  ▼
omni_decision_sample (ROS)
  │  接收血量、姿态、RFID 等
  │  运行 FSM 状态机
  │  决定下一个目标点
  ▼
Nav2 NavigateToPose
  │  路径规划 + 避障
  ▼
底盘板 USB-CDC
  (闭环)
```
